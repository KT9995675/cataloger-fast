## Cataloger Fast

Новая реализация каталогизатора Google Drive с фокусом на **мгновенные** операции по каталогу и **eventual consistency** с Google Drive.

### Принципы

- Каталог — источник истины (структура, связи, виртуальные права).
- Google Drive — “витрина”: доступ к файлу выдаётся **на чтение** только перед открытием, одному пользователю.
- Массовые операции с Drive и отзыв доступов выполняются **в фоне** по очереди/триггерам.
