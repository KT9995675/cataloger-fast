## Cataloger Fast

Оболочка типа Total Commander над Google Drive (GAS + clasp, `rootDir`: `src`).

Спецификация: [`SPEC.md`](SPEC.md) — актуальная сводка в **§0**.  
Инструкция для пользователей и управляющего: [`USER_GUIDE.md`](USER_GUIDE.md).

**Правило правок SPEC:** только **дописывать**; устаревшее не удалять — `<!-- OLD: …полный текст… -->` (§8.1). Cursor rule: [`.cursor/rules/spec-append-only.mdc`](.cursor/rules/spec-append-only.mdc).

### Команды в чате с ИИ

| Команда | Смысл |
|---|---|
| **Пишем** | Пишем код (обычно одну функцию), по спецификации |
| **обнови окно** | Контекстное окно почти заполнено → **дописать** все уточнения в `SPEC.md` + **суммирующая запись в чате** для нового/обновлённого чата. Продуктовый код не пишем. |
