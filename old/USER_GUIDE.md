# Инструкция: управление файлами в каталоге

Руководство для пользователей Google Таблицы с установленным **Каталогизатором Google Drive**.

## Что это такое

Каталог — это **виртуальное дерево папок** в таблице. На Google Drive файлы после импорта лежат в **корневой папке каталога** (`root_folder_id`). Папки в таблице — организация «на бумаге»; они не создают отдельные папки на Drive.

При загрузке файлы **сначала попадают в служебную папку `_Import`** на Drive (её не видно в дереве каталога), затем автоматически переносятся в корень. **Владелец всех файлов в каталоге — владелец таблицы.**

Имена файлов на Drive: `0237_Отчёт.pdf` — код виртуальной папки `0237` + имя.

## Где работать

Откройте лист **Catalog** — дерево файлов и папок. Слева — плюсики для сворачивания уровней.

### Колонки

| Колонка | Значение |
|---|---|
| **level_0 … level_5** | Дерево: папка или файл |
| **Размер** | Мегабайты (один знак после запятой); для папки — сумма файлов в поддереве |
| **Утверждение** | `—` или **имя утвердившего** |
| **Редактор / Комментатор / Чтение** | Кто имеет доступ |

В списках прав **группы** отображаются с префиксом **`#`** (например, `#Команда проекта`) и идут **первыми**, затем пользователи по алфавиту.

### Выделение

1. Клик по строке файла или папки.
2. Меню **📁 Каталогизатор**.
3. Нужный пункт. Можно выделить несколько строк.

---

## Меню «📁 Каталогизатор»

**Создание:** папка, файл, импорт.

**Редактирование:** переместить/копировать, переименовать, в корзину, восстановить.

**Права и утверждение:** утвердить файл, назначить права (владелец), группы.

**Служебные функции** (подменю): очистить корзину, первое сканирование, проверка целостности, исправление по отчёту, обновить дерево.

---

#### 📂 Создать папку

Виртуальная папка только в каталоге.

1. Выделите родительскую папку.
2. **📂 Создать папку** → имя без кода.

#### 📄 Создать файл

Google Документ / Таблица / Презентация.

1. Выделите целевую папку.
2. **📄 Создать файл** → тип и имя.

#### 📥 Импорт

**С компьютера**

1. Выделите целевую папку в каталоге.
2. **📥 Импорт** → **Локальный диск**.
3. Поле **Файлы** — один или несколько файлов (Cmd/Ctrl + клик).
4. Или **Папка целиком** — сохранится вложенная структура.
5. **Импортировать**.

Для загрузки редакторами должно быть настроено **веб-приложение импорта** (делает администратор). Импортёр должен быть в списке **Users** с `active=true` — тогда ему открыт доступ к папке `_Import` на Drive.

**С Google Drive**

1. **Мой Google Drive** → ссылки/ID или поиск по имени.
2. Для своих файлов можно **перенести** (тот же ID) или **скопировать**.

---

### Редактирование

#### ✏️ Переименовать

Имя без префикса кода — префикс сохранится. Для файлов обновится и на Drive.

#### ✅ Утвердить файл

Только просмотр для всех после утверждения. Отменить нельзя.

1. Один неутверждённый файл → **✅ Утвердить файл** → **Да**.

#### ↕️ Переместить / Копировать

| Действие | Результат |
|---|---|
| **Переместить** | Тот же файл на Drive, новое место в каталоге |
| **Копировать** | Новый файл на Drive, права от целевой папки |

#### 👥 Группы

Редакторы таблицы.

1. **👥 Группы** → выбрать или **+ Новая группа**.
2. Название, участники галочками → **Сохранить**.

В списке групп отображается **`#Название`**. Изменение состава обновляет Drive для файлов с этой группой в правах.

---

### Права доступа

#### 🔐 Назначить права

**Только владелец таблицы.**

1. Выделите файл/папку.
2. **🔐 Назначить права**.
3. В таблице: **группы (`#…`) сверху**, затем пользователи; роли Редактор / Комментатор / Чтение / Без доступа.
4. Опция **ко всему поддереву**.

Утверждённым файлам редакторов не назначают.

---

### Корзина

- **🗑️ В корзину** — мягкое удаление (`99_Корзина`), на Drive файлы остаются.
- **↩️ Восстановить** — из корзины.
- **🧹 Очистить корзину** — только владелец, удаление с Drive.

---

### Служебное

- **🔍 Первое сканирование** — один раз при настройке.
- **🔄 Обновить дерево** — перерисовка Catalog (после обновления схемы или ручных правок).
- **🔎 Проверка целостности** — диагностика каталога (см. ниже).

#### 🔎 Проверка целостности

Сверяет каталог с Google Drive и формирует отчёт на листе **«Отчёт целостности»** (перезаписывается при каждом запуске).

**Что проверяется:**
- файлы на Drive без записи в каталоге и наоборот;
- файлы, застрявшие в служебной папке `_Import`;
- соответствие прав в каталоге и на Drive (прямые ACL);
- **широкий ACL на `root_folder_id`** (лишние пользователи, публичный доступ);
- **физические подпапки** в корне Drive (кроме `_Import`);
- владелец файлов (должен быть владелец таблицы);
- **имя на Drive** vs каталог (`{folder_code}_имя`);
- **mime_type** каталога vs Drive;
- **`writersCanShare`** на файлах (ожидается `false`);
- **утверждённые файлы** с редакторами на Drive;
- **корзина**: согласованность `trash_parent_id`, файлы в корзине без Drive;
- **устаревшие ссылки в правах**: неизвестные/неактивные Users, пустые или отсутствующие Groups;
- ошибки структуры дерева (дубликаты, битые родители, недостижимые узлы).

**Отчёт содержит:** сводку, список проблем, все файлы с путями и правами, статистику по папкам (число файлов и суммарный размер), итог по всему каталогу.

1. **📁 Каталогизатор → 🔎 Проверка целостности**.
2. Прочитайте краткое сообщение после завершения.
3. Откройте лист **«Отчёт целостности»**.

Рекомендуется владельцу каталога после массового импорта, правок вручную на Drive или подозрения на рассинхрон.

#### 🔧 Исправление по отчёту

**Только владелец таблицы.** Проверку целостности может запустить любой пользователь.

Пошаговый мастер по последнему отчёту (хранится ~6 часов). По каждой исправимой проблеме — **Да** (исправить), **Нет** (пропустить), **Отмена** (остановить).

Сейчас автоматически исправляются (с подтверждением):
- публичный/доменный доступ на `root_folder_id`;
- лишний прямой доступ к корневой папке Drive;
- пустая физическая подпапка в корне (кроме `_Import`);
- файл на Drive без записи в каталоге — удаление с Drive;
- файл в `_Import` без записи в каталоге — удаление.

После исправлений рекомендуется повторить **🔎 Проверка целостности**.

## Типичные сценарии

### Новый документ в проект

Папка → **📄 Создать файл** или **📥 Импорт** → при необходимости **🔐 Назначить права** (владелец).

### Финальная версия

**✅ Утвердить файл** → проверить колонку «Утверждение» и отсутствие редакторов.

---

## Ограничения

- Не редактируйте лист **Catalog** вручную.
- Глубина дерева — до 5 уровней.
- Имена файлов кликабельны — открывают Drive.
- Если импорт «завис» в `_Import` на Drive — сообщите владельцу каталога (нужен `clasp push` и настроенное веб-приложение).

## Кто что может

| Действие | Редактор | Владелец |
|---|---|---|
| Создание, импорт, переименование, перенос | ✅ | ✅ |
| Утверждение, группы | ✅ | ✅ |
| Корзина / восстановление | ✅ | ✅ |
| Назначить права, очистить корзину | ❌ | ✅ |
