## v1.3.0 — staging-папка Import и косметика прав

- На Drive создаётся скрытая папка **`_Import`** внутри `root_folder_id`; ID в Settings → `import_folder_id`
- Всем **active Users** — право **Редактор** только на `_Import` (не на всю корневую папку)
- Импорт и создание файлов: загрузка в `_Import` → передача владения владельцу каталога → перенос в `root_folder_id`
- Перенос в root выполняется **от имени владельца каталога** (напрямую или через веб-приложение, action `promote`)
- Локальный импорт редакторами требует настроенное **веб-приложение** (как импорт с Drive)
- Диалог импорта: отдельные поля **Файлы** и **Папка целиком** (исправлен выбор с локального диска)
- Синхронизация прав: пустой `permissions_json` у родителя не блокирует импорт; мягкая обработка inherited-access на Drive
- Группы в UI: префикс **`#`**, сортировка групп первыми, без метки «Группа» в ячейках каталога
- Ссылки на файлы в Catalog: без лишних вызовов Drive API при известном mime-type

## v1.2.0 — управление группами

- Меню **👥 Группы** — создание, редактирование и удаление групп (редакторы таблицы)
- Диалог: название группы + галочки участников из Users
- При изменении состава — пересинхронизация Drive для файлов, где назначена группа
- При удалении группы — в правах заменяется списком участников
- Виртуальные группы каталога разворачиваются в пользователей при синхронизации на Drive

## v1.1.0 — утверждение файлов

- Колонка «Утверждение» на Catalog: `—` для неутверждённых; у утверждённых — имя утвердившего
- Утверждение через меню **✅ Утвердить файл** (выделить файл → стандартный диалог Да/Нет)
- После утверждения все права → «Просмотр», отменить нельзя
- Утверждённые файлы при назначении прав — без редакторов
- Удалён onEdit по чек-боксам (ненадёжно в GAS); старый триггер снимается при открытии таблицы

## v1.0.0 — корзина

- **В корзину** — мягкое удаление: элементы перемещаются в `99_Корзина`, файлы на Drive остаются
- **Восстановить из корзины** — возврат в `trash_parent_id` или в «Каталог», если родитель недоступен
- **Очистить корзину** — безвозвратное удаление (только владелец таблицы)
- CatalogData: колонка `trash_parent_id` (после `setupSchema`)
